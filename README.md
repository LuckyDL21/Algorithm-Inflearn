# Coding Test Archive

프로그래머스 / solved.ac 기반 코딩테스트 풀이 기록 저장소.
이직 준비를 위한 알고리즘 역량 트래킹 및 포트폴리오 자료로 활용.

## 목표

- 난이도: Silver → Platinum 단계적 상향
- 중점 유형: BFS/DFS, DP, 그리디, 이분 탐색
- 매 문제마다 **시간복잡도 분석 + 접근 과정(시행착오 포함)** 기록을 남겨서
  단순 정답 코드가 아닌 "문제 해결 과정" 자체를 포트폴리오화

## 폴더 구조

```
.
├── README.md                 # 현재 파일 (전체 이력 관리)
├── greedy/                   # 그리디
│   └── 단속카메라/
│       ├── README.md         # 문제별 상세 풀이 과정 (방법1 vs 방법2 등)
│       └── solution.py
├── dp/                       # 동적 계획법
├── bfs_dfs/                  # 그래프 탐색
├── binary_search/            # 이분 탐색
└── etc/
```

각 문제 폴더의 README는 다음 형식을 따름:
- 문제 요약 및 링크
- 시도한 방법들 (틀렸거나 비효율적이었던 접근 포함)
- 최종 정답 코드 및 시간복잡도
- 배운 점 / 다음에 비슷한 유형 만났을 때 체크할 것

## 회고 로그

### 2026-08-08
- 단속카메라(그리디) 풀이. 처음엔 `while` + `deque` 재필터링 구조로 접근해서
  정답은 맞았지만 O(n²) 구조였음. "정렬해두면 재필터링 없이 한 번의 순회로
  충분하다"는 포인트를 놓쳤던 것이 핵심 실수. 그리디 초기값 설정
  (`float('-inf')`) 관련 엣지케이스도 함께 학습.

### 2026-08-17
- 이중우선순위큐(힙) 풀이. 첫 시도는 리스트 + `max()`/`min()`/`remove()`로
  정답은 맞혔지만 O(n²) 구조였음. heapq를 최소힙/최대힙 이중으로 써서
  삭제를 O(log n)으로 줄이되, 두 힙이 서로의 삭제를 모르는 동기화 문제를
  `delete_set` + lazy deletion으로 해결하는 패턴을 학습.
